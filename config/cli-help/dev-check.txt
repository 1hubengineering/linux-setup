usage: dev-check [-h] [--version] [--completion {bash,zsh,fish}] [--network] [--json]
                 [PATH]

Read-only checks for a project's local development prerequisites.

positional arguments:
  PATH

options:
  -h, --help            show this help message and exit
  --version             show program's version number and exit
  --completion {bash,zsh,fish}
                        Print a shell completion script without changing files
  --network             Explicitly probe npm registry HTTPS using configured proxy/CA
                        trust
  --json                Print structured check results
